# DeepSeek 历史对话复用（试用版）

## 用户流程

1. 在 Chrome 扩展程序页面重新加载本项目的 DeepShare，再刷新 DeepSeek 页面。
2. 打开 DeepSeek「系统设置 → 数据管理 → 导出所有历史对话」。首次使用先等待官方生成导出包，然后点 **下载**。同步最新对话时，先点 **重新导出**，待生成完成后再下载；直接下载现有导出包只会获取上次导出的内容。插件提示中的“重新导出”和“下载”会触发原生同名按钮，沿用官方流程；切换设置标签后，提示会重新定位到导出行下方。
3. DeepShare 自动识别这次官方下载，在浏览器本地建立历史库。设置行下方会显示保存结果。
4. 开启新对话，点击输入框下方、附件按钮左侧的 **导入历史对话**。
5. 搜索标题或正文，匹配词会在左侧标题和右侧预览中高亮，清空搜索后恢复。普通模式点击对话预览，点击“多选”后用圆形勾选框选择多条，点击整行切换勾选，点击 × 或按 Esc 退出多选。搜索、预览和导入均使用时间最近的分支，无需选择。
6. 点击 **导入**，文件交给 DeepSeek 后选择窗口自动关闭，直接回到输入框查看附件并继续提问。插件不会发送问题。
7. 自动附加失败时，可点 **下载Markdown**，再通过 DeepSeek 原生附件按钮上传文件。
8. 如需 Word，可点 **导出 Word**，沿用插件已有的文档转换服务、API-Key 和模板设置下载 `.docx`。仅发送所选对话的最新分支，思考内容同样由底部开关控制；保留历史选择窗口，沿用现有文档下载流程；转换状态提示置于弹窗上方，关闭窗口后仍可显示。

下载 Markdown 和导出 Word 均保留选择窗口；仅导入成功交给附件控件后自动关闭。预览区不显示生成、读取或同步状态提示；操作失败使用现有浮动提示，正文布局保持不变。

单个对话的文件名为 `对话标题.md`；多个对话为 `第一个对话标题等多个对话.md`（按列表顺序）。自动导入与下载使用相同命名，文件名不支持的字符会被清理。
未勾选时，下载 Markdown、导出 Word 和导入均使用当前预览的对话；有勾选时仅使用勾选的对话。切换当前对话时右侧预览回到顶部，左侧列表保持滚动位置。对话标题保留在正文预览内，滚动时吸顶并以不透明背景遮住经过的正文。多选时不切换右侧预览；退出多选会清空勾选，恢复进入多选前的当前对话。Esc 在多选时先退出多选，再按一次关闭弹窗。没有任何可用对话时，操作按钮禁用。

窗口支持点击外部、右上角关闭和 Esc 关闭。打开与关闭复用原生设置的 100 ms 动画时长及缓动变量，缩放范围为 0.96–1，遮罩同步淡入淡出并使用 2 px 模糊。系统开启减少动态效果时缩短动画。

桌面窗口为 920×600，保留原生设置的 24 px 圆角，标题左侧 24 px、顶部 22 px，字体 16 px / 500。日期右侧使用同一个 22 px 小按钮切换“多选／退出多选”，两种状态都有原生深灰 tooltip，不额外显示多选标题行。勾选框按原生 200 ms 宽度和透明度动画展开、收起，标题同步平移；日期独占 22 px 的不透明吸顶行。搜索框与列表使用独立圆角背景，中间间隔 10 px；列表左右预留对称的滚动条空间，对话行文字左右内边距均为 10 px。底部操作栏上方间距为 10 px、下方为 14 px。列表和正文滚动条统一沿用原生浅灰／深色变量、8 px 圆角滑块（最短 48 px，右侧留 3 px）；鼠标进入各自区域时显示，移出后停留 1 秒再用 100 ms 淡出，重新进入立即取消隐藏，无需先滚动，键盘聚焦区域内控件时也可见。悬停滑块加深并加宽至 10 px。列表按今天、昨天、7 天内、30 天内和月份分组，采用原生的 40 px 单行行高与 14 px 标题；当前对话使用原生侧栏的浅蓝背景、蓝色文字和 12 px 圆角；多选框采用圆形蓝底白色对勾。关闭按钮使用相同的 SVG 路径、14 px 图标及 28 px 点击区域，并复用原生悬停颜色和过渡变量。打开时焦点落在窗口本身，键盘导航仍保留焦点提示。

底部工具按“刷新 → 导入 → 清除本地历史库”排列。这里的小“导入”选择已下载的官方 ZIP 或解压后的 `conversations.json`，在本地解析后替换历史库，保留当前窗口；不会把文件发送到 DeepSeek。数据分块传给扩展后台，校验或写入失败时保留旧库。右侧“导入”仍用于把所选对话附加到当前聊天。

已下载到磁盘的旧 ZIP 不会被自动扫描，可以使用底部“导入”选择文件，或者从 DeepSeek 设置里再点一次“下载”。首次导出准备期间没有文件可捕获，必须等官方生成完毕并点击下载。

## 数据与边界

- 只处理官方导出存储域名 `deepseek-chat-history-exports-prod.obs.cn-east-3.myhuaweicloud.com` 下的 HTTPS ZIP 下载。
- 新增 `downloads` 权限以接收下载事件，以及上述单一域名的读取权限。浏览器可能提示确认新增权限。
- 插件根据官方下载事件，使用临时签名链接读取同一个导出包。原 ZIP 的正常下载不受影响。链接不持久保存，不输出到日志。
- ZIP 在本地解压，完整对话及分支保存在扩展自己的 IndexedDB 中；不经过 DeepShare 服务器，也不进入 Chrome 同步存储。
- 历史库属于当前浏览器中的这个扩展，不随 DeepSeek 登录账号自动切换。切换账号时，可先清除本地历史库，再导出目标账号的记录。
- 点击“导出 Word”会把所选内容发送到插件配置的 DeepShare 文档转换服务，使用已有 API-Key 和转换额度。MD 下载仍在本地生成。
- 新一次成功导出会原子替换历史库，解析、下载或存储失败时保留旧库。清除本地库使用按钮内二次确认：第一次点击变为“确认清除？”，再次点击才清除，不弹窗；点击其他位置或移开键盘焦点会取消确认。DeepSeek 原记录和已下载文件不受影响。
- 只导出最新分支的提问与回答，可选包含思考内容。代码、Markdown、公式原文保留。原附件只记录文件名；附件二进制、搜索及工具元数据不包含在生成的 MD 中。
- 当前每个导出 ZIP、解压后的 conversations.json 限制为 64 MB。不支持 ZIP64、分卷或加密包。
- 导入触发原生文件控件后自动关闭选择窗口；上传进度和结果以 DeepSeek 的附件状态为准。文件大小、数量及账号限制由 DeepSeek 决定。
- 这是本地试用实现，尚未发布到扩展商店。设置行匹配和附件控件接入仍需跟随 DeepSeek 页面变化维护。

## 实现结构

- `scripts/history/core.js`：有大小上限和 CRC 校验的 ZIP 读取、官方 fragments/mapping 解析、最新分支提取、Markdown 生成。
- `scripts/history/store.js`：扩展 IndexedDB 的事务读写。
- `scripts/history/background.js`：监听官方下载、更新历史库、向 DeepSeek 内容脚本提供读取与清除功能。
- `scripts/history/content.js`、`styles/history.css`：设置提示、历史选择窗口、MD 下载与原生附件上传。

## 验证

运行 `node --test tests/background-injection.test.cjs tests/history/*.test.cjs`，不需要安装依赖。覆盖 ZIP 两种压缩方式、损坏数据、分支顺序、思考开关、Markdown 保真、下载去重、来源限制、失败保留旧库以及安装注入的权限与标签页状态。

扩展更新时不再向旧页面重复注入整套脚本，避免残留按钮和旧监听器。更新后刷新 DeepSeek 页面以加载新版；首次安装仅尝试注入已授权、已加载且未休眠的匹配页面，访问状态变化导致的拒绝会跳过。

打开 `tests/history/demo.html` 可用虚构对话做浏览器交互测试。点击模拟下载后，可测试搜索、选择、最新分支预览、文件附加与本地 IndexedDB 持久化。示例页面不会向网络上传数据。

本机真实导出包已验证：454 个对话、1,973 条消息、17 个多分支对话。真实文件内容未加入代码仓库或测试夹具。
按最新分支统计，1,930 条消息中有 174 条包含非空思考内容，分布于 108 个对话；已验证开关开启时完整保留 THINK 原文、默认关闭时不加入思考段落。Word 入口通过离线转换事件模拟验证，不发送真实历史内容或消耗转换额度。
